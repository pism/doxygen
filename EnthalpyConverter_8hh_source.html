109//! An EnthalpyConverter for use in verification tests.
110
111/*! Treats ice at any temperature below 10^6 kelvin as cold (= zero liquid fraction).
112
113 The pressure dependence of the pressure-melting temperature is neglected.c;
114
115 Note: Any instance of FlowLaw uses an EnthalpyConverter; this is
116 the one used in cold mode verification code.
117
118
119 This is the special enthalpy converter that is used in
120 temperature-based verification tests only.
121
122 In these tests ice temperatures in an exact solution may exceed the
123 pressure-melting temperature, but we still want to pretend that this
124 ice is "cold" to ensure that the map from enthalpy to temperature is
125 one-to-one. (Normally enthalpy is mapped to the (temperature, water
126 fraction) pair; here water fraction is zero, so enthalpy <-->
127 (temperature, 0.)
128
129 So, I had to pick a threshold (melting) temperature that is above
130 all ice temperatures. 10^6K was chosen.
131*/
132class ColdEnthalpyConverter : public EnthalpyConverter {
133public:
134 ColdEnthalpyConverter(const Config &config);
135 virtual ~ColdEnthalpyConverter() = default;
136};
